CLINORQ LOGO SETI (SVG)
=======================
Yazi tipi: Sora SemiBold (600), harfler path'e cevrildi (font kurulumu gerekmez).

Klasorler
- symbol/      Sadece q isareti
- wordmark/    "clinorq" yazisi (q = isaret)
- stacked/     Isaret ustte, yazi altta
- horizontal/  Isaret solda, yazi sagda
- app-icon/    512x512 uygulama ikonlari (light / dark / blue)
- favicon/     Tarayici sekmesi ikonu

Renk varyantlari
- color    : Acik zemin icin tam renk
- reverse  : Koyu (lacivert) zemin icin tam renk
- navy     : Tek renk lacivert
- black    : Tek renk siyah (baski, faks, muhur)
- white    : Tek renk beyaz (koyu zemin / fotograf uzeri)

Renkler
- Lacivert  #0B1F3A   (yazi + q govdesi)
- Mavi      #1D7BEA   (koyu zeminde #3A92F7)
- Teal      #0F8A85   (koyu zeminde #1FB0A7)
- Koyu zemin / ikon karo  #0B2447
